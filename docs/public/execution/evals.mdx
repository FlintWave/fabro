---
title: "Evaluating workflows"
description: "Run a fixed set of known tasks against a workflow and gate on pass rate"
---

`fabro eval` runs every case in a suite file, records pass or fail for each, and exits 0 when the pass rate meets the threshold. Use it to catch regressions after changing prompts, models, or hooks.

## Suite file format

A suite is a TOML file with a `[suite]` header and one or more `[[case]]` entries:

```toml title="smoke.toml"
_version = 1

[suite]
name = "factory-smoke"
pass_threshold = 0.8

[[case]]
name = "fix-add"
workflow = "workflows/fix/workflow.toml"
goal_file = "cases/fix-add/goal.md"

[[case]]
name = "rename-method"
workflow = "workflows/fix/workflow.toml"
target_from = "cases/rename-method/repo"
inputs = { method = "oldName" }
timeout = "5m"
environment = "local"
```

### `[suite]` fields

| Field | Required | Description |
|---|---|---|
| `name` | Yes | Suite name, used in reports and JSON output. |
| `pass_threshold` | No | Fraction of cases that must pass (0.0 to 1.0). Defaults to 1.0. |

### `[[case]]` fields

| Field | Required | Description |
|---|---|---|
| `name` | Yes | Case name, unique within the suite. Lowercase letters, digits, and hyphens only. |
| `workflow` | Yes | Path to the workflow TOML. |
| `target_from` | No | Directory to use as the run workspace. Defaults to the suite file's directory. |
| `goal_file` | No | Path to a file whose contents become the run goal. |
| `inputs` | No | Key-value pairs passed to the run as input overrides. Values are strings. |
| `environment` | No | Named environment for agent tools. Overrides the `--environment` CLI flag. |
| `timeout` | No | How long to wait for the case's run: a number of seconds, or a number with an `s`, `m`, or `h` suffix (e.g. `"90s"`, `"5m"`). Defaults to `"60m"`. |

Relative paths resolve against the suite file's directory, and every path must exist when the suite loads. A suite needs at least one case.

## Results and exit codes

Cases run one at a time, in file order. Each ends with one of four results:

| Result | Meaning |
|---|---|
| `passed` | The run succeeded. |
| `failed` | The run reached any other terminal status. |
| `timeout` | The run was still going when the case's `timeout` expired; `fabro eval` cancels the run and waits up to 30 seconds for it to stop. |
| `error` | The run could not be created or started. |

The pass rate is the number of `passed` cases divided by the number of cases run. `fabro eval` exits 0 when the pass rate is at least `pass_threshold`, and 1 otherwise.

Each run carries the labels `eval.suite=<suite name>` and `eval.case=<case name>`.

## Running a subset

Pass `--only` one or more times to restrict the run to specific cases:

```bash
fabro eval smoke.toml --only fix-add --only rename-method
```

## JSON output

`--json` prints the report as JSON on stdout in place of the per-case lines and summary. `--output report.json` also writes the same report to a file, with or without `--json`.
